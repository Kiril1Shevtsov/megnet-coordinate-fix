# Протокол и результаты

Задача: прогноз ширины запрещённой зоны в eV по дефектной кристаллической структуре. Вариант baseline сохраняет проверку принадлежности скалярных координат; corrected проверяет совпадение тройки координат. Округление в обоих вариантах одинаковое.

| Разбиение | Seed | EwT: исходный → исправленный, % | MAE: исходный → исправленный, meV |
|---:|---:|---:|---:|
| 101 | 11 | 55,03 → 75,80 | 24,88 → 15,48 |
| 101 | 29 | 52,89 → 76,45 | 25,05 → 14,97 |
| 202 | 11 | 62,96 → 75,59 | 22,18 → 16,52 |
| 202 | 29 | 44,75 → 79,23 | 32,30 → 13,55 |
| 303 | 11 | 70,66 → 81,58 | 17,40 → 12,59 |
| 303 | 29 | 26,55 → 76,87 | 40,28 → 15,22 |

При усреднении по двум инициализациям прибавка EwT для разбиений 101, 202 и 303 составляет +22,16, +23,55 и +30,62 п.п. соответственно. Число изменённых структур в обучении / валидации / тесте: 13/0/1, 11/1/2 и 12/2/0. Выборки повторно используют один набор: попарные пересечения тестовых частей 68, 80 и 68 структур; всего 1195 уникальных материалов. Два запуска на одном разбиении не являются двумя независимыми внешними тестами.

## Настройки

MEGNet 1.2.9, TensorFlow/Keras 2.7, Python 3.9.25, CPU, по одному потоку. Общая решётка: a=b=25,5225256 Å, c=14,879004 Å; углы 90°, 90°, 120°. Отсечка графа 20 Å, 100 центров радиального базиса от 0 до 21, ширина 0,5. Остальные параметры задаёт конструктор MEGNetModel в указанной версии. Размер батча 128, 17 шагов на эпоху, 2040 шагов на запуск.

Сначала сортируем 2966 объектов по ID. RandomState(split) задаёт перестановку; первые 2060 объектов идут в обучение, следующие 439 в валидацию, оставшиеся 467 в тест. RandomState(split × 1000 + seed) задаёт одинаковую для парных моделей отдельную последовательность из 120 перестановок обучающих примеров. Все запуски доведены до финальной эпохи, без отбора лучшей инициализации или эпохи. Критерий EwT строгий: абсолютная ошибка < 0,02 eV.

## Переобучение

После подготовки данных и окружения по [основной инструкции](../README.md):

~~~bash
python experiment.py prepare
for split in 101 202 303; do
  for seed in 11 29; do
    for variant in baseline corrected; do
      python experiment.py train --split "$split" --seed "$seed" --variant "$variant"
    done
  done
done
~~~

В runs/ будут исходные веса, финальные модели и прогнозы нового прогона. Комплектные веса не перезаписываются. Численное побитовое совпадение при смене платформы или сборки TensorFlow не предполагается. Для визуализации здесь есть отдельный скрипт plot_results.py.
